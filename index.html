What’s inside

  • 3 styles × 2 modes – switched with the data-me and data-bs-theme attributes, remembered in localStorage.
  • Plain CSS layers on top of Bootstrap: me-theme, me-widgets, me-me1, me-me2, me-shapes.
  • Game widgets – the Mission Computer wheel, Options rows, pickers with arrows, On/Off toggles, sliders.
  • SVG icons and 9-slice skins for panels, buttons and scrollbars.
  • Measuring tools in Python (tools/) to compare the mockups with the reference.

Usage

<html data-me="me3" data-bs-theme="dark"> <link rel="stylesheet" href="bootstrap.min.css"> <link rel="stylesheet" href="css/me-theme.css"> <link rel="stylesheet" href="css/me-widgets.css"> <link rel="stylesheet" href="css/me-me2.css"> <link rel="stylesheet" href="css/me-me1.css"> <link rel="stylesheet" href="css/me-shapes.css"> <script src="js/me.js"></script>
